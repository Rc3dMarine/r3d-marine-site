AXOPAR 37 — RENDER UPLOAD FOLDER
================================

Add the Axopar 37 renders directly to this folder:

  assets/models/axopar-37/

Name the files:
  01.png   Main image (also shown on the Hulls page)
  02.png   Second gallery image (optional)
  03.png   Third gallery image (optional)
  04.png   Fourth gallery image (optional)
  05.png   Fifth gallery image (optional)

Use lowercase .png exactly for 01.png. For additional images,
the gallery also detects .PNG, .jpg, .jpeg and .webp.

You can upload 01.png through 05.png using the GitHub
Add file > Upload files option inside this folder.
Keep the files numbered consecutively, without gaps.

Until 01.png exists, the website automatically displays
placeholder.svg instead. Once 01.png is uploaded, the actual
render is used automatically without editing any website code.

Suggested: PNG or WebP, landscape, around 1600–2000 px wide
for sharp images without needlessly large downloads.

Do not delete placeholder.svg: it is used when the first
render is missing or temporarily unavailable.
